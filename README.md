🎯 Quiz Arena Web Application
📌 Project Overview

Quiz Arena is a web-based quiz application designed to test users' knowledge through interactive quizzes. It provides a user-friendly interface where users can attempt quizzes, view scores, and improve their learning experience.

This project is ideal for students and learners who want to practice multiple-choice questions in an engaging way.

🚀 Features
📝 User Registration & Login System
🎯 Multiple Choice Questions (MCQs)
⏱️ Timed Quiz (optional feature)
📊 Score Calculation & Result Display
🔄 Dynamic Question Loading
💻 Simple & Clean UI
🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Python (Flask)
Database: MySQL
Tools: VS Code / IntelliJ / Jupyter Notebook
📂 Project Structure
QUIZ-ARENA/

⚙️ Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/anjalibpatil09-ctrl/QUIZ-AREANA.git
cd QUIZ-AREANA
2️⃣ Install Dependencies
pip install -r requirements.txt
3️⃣ Setup Database
Open MySQL
Create a database (e.g., quiz_arena)
Import database.sql
4️⃣ Configure Database in app.py
mysql.connector.connect(
    host="localhost",
    user="root",
    password="your_password",
    database="quiz_arena"
)
5️⃣ Run the Application
python app.py
6️⃣ Open in Browser
http://127.0.0.1:5000/
